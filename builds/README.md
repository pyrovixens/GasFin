# GastFin Pro - Distribuciones Multiplataforma

Este directorio contiene las 3 versiones de distribución independientes de **GastFin Pro**:

---

## 📁 1. `builds/windows-pc/` (Windows 10 / 11)
- **`win-unpacked/GastFin Pro.exe`**: Ejecutable nativo para Windows (.exe) directo y portable.
- Guía completa de uso en [`builds/windows-pc/README.md`](file:///Users/macbook/Desktop/Sistema%20de%20Costos/builds/windows-pc/README.md).

---

## 📁 2. `builds/android-apk/` (Android Smartphones & Tablets)
- Proyecto nativo de Android listo para compilar el **`.apk`** con Gradle (`./gradlew assembleDebug`) o abrir con 1 clic en **Android Studio**.
- Guía de compilación en [`builds/android-apk/README.md`](file:///Users/macbook/Desktop/Sistema%20de%20Costos/builds/android-apk/README.md).

---

## 📁 3. `builds/ios-app/` (iPhone & iPad)
- Proyecto nativo de Xcode (**`App.xcodeproj`**) listo para abrir en Mac y compilar para iPhone, iPad o simulador de iOS.
- Guía de apertura en [`builds/ios-app/README.md`](file:///Users/macbook/Desktop/Sistema%20de%20Costos/builds/ios-app/README.md).
