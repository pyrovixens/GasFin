# GastFin Pro - Versión de Escritorio para Windows (.exe)

Esta carpeta contiene la distribución de escritorio nativa para sistemas **Windows 10 / 11 (64-bit)**.

---

## 📦 Archivos Disponibles en esta Carpeta

- **`win-unpacked/GastFin Pro.exe`**: Ejecutable directo portátil listo para usar sin instalación previa.
- **`GastFin Pro Setup 1.0.0.exe`**: Instalador oficial para Windows con acceso directo en el Escritorio y Menú Inicio.
- **`GastFin Pro 1.0.0.exe`**: Versión 100% portable para llevar en un pendrive USB.

---

## 🚀 Cómo Ejecutar en Windows

1. **Opción Rápida**: Copia la carpeta `win-unpacked` a tu PC y haz doble clic en `GastFin Pro.exe`.
2. **Opción Instalador**: Ejecuta `GastFin Pro Setup 1.0.0.exe` y sigue los pasos del asistente de instalación.

---

## 🛠️ Recompilar desde el Código Fuente

Si realizas cambios en el código y deseas generar un nuevo `.exe`:

```bash
npm run build:win
```
